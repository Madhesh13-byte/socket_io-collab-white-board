# 🖊️ Real-Time Collaborative Whiteboard

A real-time whiteboard and chat app that allows users to draw together in shared rooms. Built with React, Node.js, Express, Socket.IO, and MongoDB.

---

## 🚀 Features

- 🎨 Real-time collaborative whiteboard
- 🧽 Pen and Eraser tools
- 🎚️ Brush size and color picker
- 🗑️ Clear canvas functionality
- 💬 Room-based live chat
- 🔐 Unique room code generation

---

## 🛠️ Tech Stack

- **Frontend**: React.js
- **Backend**: Node.js, Express.js
- **Realtime Communication**: Socket.IO
- **Database**: MongoDB (Mongoose)
